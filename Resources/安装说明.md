# 模式启动器 WorkMode · 安装说明

一个常驻在屏幕右上角菜单栏的小工具：点一下图标，选「工作模式」或「娱乐模式」，一键把该模式下的应用全部打开。**已经在运行的应用会自动跳过**，不会重复开窗。不使用的时候退出即可，不会开机自启。

## 系统要求

- macOS 12 及以上
- Apple Silicon（M 系列）和 Intel Mac 都支持

## 安装

1. 双击打开 `WorkMode.dmg`
2. 把窗口里的 `WorkMode.app` 拖到 `Applications` 文件夹（窗口里已经放好了 Applications 的快捷入口）
3. 双击 `WorkMode.app` 启动，屏幕右上角会出现一个 ⚡️ 图标

## 首次打开被系统拦截怎么办

因为这个应用没有使用付费的苹果开发者证书签名，macOS 会把它拦在门外。这是正常现象，不是文件损坏，任选一种方式放行：

**方法一（最简单）**
在 Finder 里**右键**（或按住 Control 点一下）`WorkMode.app` → 选「打开」→ 在弹出的对话框里再点「打开」。之后就能正常双击了。

**方法二**
打开「系统设置 → 隐私与安全性」，往下滚到「安全性」一栏，会看到「WorkMode 已阻止使用，因为来自身份不明的开发者」，点右边的「**仍要打开**」。

**方法三（终端）**
```bash
xattr -dr com.apple.quarantine /Applications/WorkMode.app
```

## 怎么用

- 点菜单栏 ⚡️ → 展开某个模式 → 点最上面加粗的「**▶ 一键启动**」
- 模式里每个应用单独点一下，就只启动它一个；已经在跑的应用前面会显示 ✓
- 点「设置…」可以：新建/删除模式、改名字和图标、往模式里添加应用（支持按住 ⌘ 多选，也可以直接把 .app 拖进列表）
- **首次启动只有「💼 工作模式」和「🎮 娱乐模式」两个空模式**，不会去扫描你装了什么软件。想要哪些应用由你自己添加：点「添加应用…」按住 ⌘ 一次选多个，或者直接从 Finder 把 .app 拖进列表

## 开机自启

**默认开启**：首次启动时会自动把自己加入登录项，以后开机/登录就会自己起来，菜单栏直接出现 ⚡️。

不想让它开机启动：点菜单栏 ⚡️ → 「**开机自动启动**」，把前面的 ✓ 点掉即可（再点一次又能打开）。这个开关只影响开机启动，不影响你现在手动打开使用。

（需要 macOS 13 及以上；如果系统设置里没看到，也可以手动添加：系统设置 → 通用 → 登录项与扩展 → 把 WorkMode 加进去。）

配置保存在 `~/Library/Application Support/WorkMode/modes.json`，卸载时删掉这个目录即可完全清除。

## 卸载

1. 菜单栏 ⚡️ → 「退出模式启动器」
2. 删除 `/Applications/WorkMode.app`
3. 如需彻底清除配置：`rm -rf ~/Library/Application\ Support/WorkMode`
